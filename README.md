| 根目录 | 入口 00/01/02/03、出题原则、维护文件 | 教师侧 |

## 三条硬规则（摘要，正文见 [AGENTS.md](AGENTS.md)）

1. **可见性按目录定**：`题库/<批次>/` 可整份给学习者，`审查/` 只给审查方，`解析/` 在独立作答前不打开也不作为提示。放错目录按泄露处理。
2. **未验收不等于可投放**：生成侧参考推导不是验收结论；题面修订后不继承旧版本的结论；验收通过也还要按当前学情做适配判断。
3. **只有真实作答才算证据**：不因回答正确、表示理解或聊得久就判定掌握。资料错误、AI 错误与已撤回的诊断不写进学习者记录，已撤回项见[状态文件](学情/30_考研数学一_当前学习状态.md)第4节。
