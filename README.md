## 按角色加载

- 教学与学情交接：[42教学入口](42_教学agent提示词.md)。先选择当前科目，再读其状态、必要记录和题面，不一次加载全库答案。
- 路线与出题：[41出题入口](41_出题agent提示词.md)。先读学情，按用户当前授权生成题面；不默认写答案或自行验收。
- 独立审查：[批次清单](99_工作包文件与版本清单.md#题目审查批次)定位审查材料，再按[Validation协议](数学题_Validation_Protocol.md)分阶段接收；不把本库学情和参考答案塞进盲验上下文。
- 首次使用或只做直接任务：[使用说明](00_先读我_使用说明.md) → [数学启动入口](00_数学教学_启动入口.md)，按当前动作读取必需模块。

## 维护

规则唯一出处是[AGENTS.md](AGENTS.md)，事件字段在[记录格式](复习记录/00_格式与规则.md)，批次版本与审查状态在[99清单](99_工作包文件与版本清单.md)。写回使用当前目标分支的最新版本，独立分支和PR保留变更；具体执行与无写入工具时的交接方式见41、42。

修改后先运行 `python 98_刷新校验清单.py`，再运行 `python 97_检查摆放.py`。检查通过仅表示文件摆放与清单一致，上游缺件提醒见90；不会证明题目或学生已验收。
